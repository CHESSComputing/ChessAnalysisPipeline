Return a logger that writes only to the active task log file.

Unlike get_logger(), the returned logger is not attached to the shared application log handler. If no task context is active the logger has no handlers and its output is silently discarded.

task_log_context(log_path)[source]

Context manager that tees log output to a per-task append-only file.

While active, all loggers created via get_logger() write to log_path in addition to the shared rotating log file, using the same formatter. Raw stdout/stderr writes are also teed to the same file without any additional formatting. The file is always opened in append mode so successive calls accumulate rather than overwrite.

saxswaxs_to_chap(map_config_file, tool_config_files, outputdir, detector_filename='detector_config.yaml', pyfai_filename='pyfai_integration_processor_config.yaml', correction_filename='corrections_config.yaml', fits_filename='fits_config.yaml', pipeline_filename='pipeline.yaml')[source]

Build CHAP pipeline config files from old-style saxswaxs workflow configs.

Converts old-style tool config files to CHAP-format detector, pyFAI integration, and corrections config files via convert_configs(), then composes the CHAP pipeline config YAML via make_pipeline().

Parameters:

  • map_config_file (str) – Path to the map config YAML file.

  • tool_config_files (list[str]) – List of tool config YAML file paths.

  • outputdir (str) – Directory in which to write the output CHAP config files.

  • detector_filename (str, optional) – Output filename for the detector config YAML, defaults to 'detector_config.yaml'.

  • pyfai_filename (str, optional) – Output filename for the pyFAI integration processor config YAML, defaults to 'pyfai_integration_processor_config.yaml'.

  • correction_filename (str, optional) – Output filename for the corrections config YAML, defaults to 'corrections_config.yaml'.

  • fits_filename (str, optional) – Output filename for the fits config YAML, defaults to 'fits_config.yaml'.

  • pipeline_filename (str, optional) – Output filename for the CHAP pipeline config YAML, defaults to 'pipeline.yaml'.
